## Goals

- Share knowledge about good system administration practices using Docker;
- Install and use Docker;
- Manage containers in development, staging, and production environments;
- Build Docker images from instructions written in Dockerfiles;
- Run a set of containers using Docker Compose.

## Who is it for?

SREs, cloud architects, software developers, software architects, software product managers, system administrators, Information Technology teachers, and students.

## Prerequisites

- Basic knowledge of the GNU/Linux operating system;
- Basic knowledge of TCP/IP, IP addressing, and ports;
- Familiarity with the GNU/Linux console, including the commands: ls, cd, pwd, mkdir, rmdir, rm, echo, cat, tail, ps, top, kill, ping, vim, nano.

## Syllabus

- Introduction to Docker: definition, features, history, architecture, support, communities, and documentation;
- Containers and images;
- Containers versus virtual machines;
- Docker Host;
- DockerFile;
- Docker Hub;
- Sharing volumes between the Docker Host and the containers;
- Docker Registry;
- Docker Network;
- Docker Compose;
- Security tips for building images and managing Docker containers;
- Tools to support the production environment;
- Hands-on project: each group will simulate a development and operations team. The goal is to practice the workflow, from building a Docker image to deploying it to the production environment.
