🇺🇸 [en-US] I customized a Docker image with troubleshooting tools...

If anyone is interested, feel free to use/contribute: [https://github.com/aeciopires/nettools](https://github.com/aeciopires/nettools)

It runs on ARM64 and AMD64 and also has a deployment file and instructions for running on K8s.

The base image is Alpine and runs as root, so it's easy to install other tools that don't come by default.
