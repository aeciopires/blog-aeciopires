## Hello!

### I'm sharing a document written by **Victor Igor**, who works with me at Dynavideo.

This document teaches how to configure MikroTik to check whether a link is working and, in case of failure, redirect the internal network traffic through another redundancy or backup link. The document also explains how to implement NAT rules on the Internet access links. The text is very straightforward: it shows the commands to use and explains what each command does, so that a beginner can understand and implement this solution without much difficulty.
