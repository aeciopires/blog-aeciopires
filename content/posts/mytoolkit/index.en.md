It has been a long time since my last post, but I haven't been idle: I learned and built a lot in the meantime, and I'm going to start publishing a series of posts about the open source applications in [my GitHub repositories](https://github.com/aeciopires?tab=repositories).

I'll start with [mytoolkit](https://github.com/aeciopires/mytoolkit).

**MyToolkit** is a set of tools for everyday tasks of developers, DevOps engineers, analysts, and other IT professionals. By bringing several tools together in a single place, it makes converting, formatting, generating code, and handling data fast, practical, and secure, without having to switch between multiple websites and apps.

You can run it locally without worrying about sharing sensitive data on websites.

It is distributed as a single Go binary that, by default, runs as a web application (REST API + server-rendered interface) or as a CLI for any individual tool.

Get more information at: [mytoolkit](https://github.com/aeciopires/mytoolkit).
