Countdown is one of the web applications I developed in my spare time over the last few months. There are other tools available in my public GitHub repositories: [https://github.com/aeciopires?tab=repositories](https://github.com/aeciopires?tab=repositories)

The goal of this application is to display a countdown timer and a stopwatch. When I teach online classes, I need to show a timer on the screen so the students know when to come back… Instead of opening a website full of ads, I decided to create a tool that runs locally.

Feel free to use it.

See the usage details at: [https://github.com/aeciopires/countdown](https://github.com/aeciopires/countdown)
