Private, online, live classes (also available for groups).

Kubernetes is a portable, extensible, open source platform that manages containerized workloads and applications, and it also makes declarative configuration and automation easier.

**Price:** R$ 800.00 paid upfront or R$ 950 in up to 5 interest-free installments through PagSeguro.

**Duration:** 16 hours.

## Goals

- Share knowledge about best practices for system administration using Kubernetes;
- Create and manage a Kubernetes cluster;
- Manage deployments, replicaSets, pods, services, nodes, and other Kubernetes objects;
- Install and use Helm and kubectl to install and configure applications on Kubernetes;
- Develop your own Helm charts.

## Who is it for?

SREs, cloud architects, platform engineers, software developers, software architects, software product managers, system administrators, Information Technology teachers, and students.

## Prerequisites

- Knowledge of Docker and container management ([how about taking this course first?](/en/curso-docker/));
- Basic knowledge of git;
- Basic knowledge of the GNU/Linux operating system;
- Basic knowledge of TCP/IP, IP addressing, and ports;
- Familiarity with the GNU/Linux console, including the commands: ls, cd, pwd, mkdir, rmdir, rm, echo, cat, tail, ps, top, kill, ping, vim, nano.
